# 聊天滚动扩展 E2E 记录（2026-10-22）

> 目的：验证 v0.4.2 中「聊天尾部窗口扩展视口跳底」修复（commit 1502404）在真实 dev 实例上的表现。
> 结论：**通过**。向上加载更早消息时，视口锚点保持稳定，未出现跳底或明显跳动。

## 环境

- 应用：Better SageRead dev 实例（Tauri），页面 http://localhost:1420
- CDP：http://127.0.0.1:9223
- 数据：dev 数据目录 com.bettersageread.dev；使用真实历史会话（含 28 条消息的全局会话）
- 方法：CDP Runtime.evaluate 驱动，程序化设置 scrollTop 触发 load-more（与用户滚轮触发的是同一 IntersectionObserver + expandWindow 路径）

## 测试步骤

1. 打开一个消息数 > 初始窗口（INITIAL_WINDOW = 6）的会话；
2. 记录聊天滚动容器、当前渲染消息数、scrollTop / scrollHeight / clientHeight；
3. 将容器滚到顶部（scrollTop = 0）并派发 scroll 事件；
4. 连续采样（每次扩展 + 帧级采样），记录：
   - 渲染消息数（是否 6 → 12 → 18 → 24 递增）；
   - 滚动容器 scrollTop 与最大可滚动距离（判断是否跳到底部）；
   - 扩展前视口内第一条消息的 id 与其相对滚动容器顶部的偏移（修复采用的锚点）；
5. 检查锚点偏移是否稳定（理想：≤1px），scrollTop 是否等于 max（跳底特征）。

## 结果

### 第 1 次扩展（旧窗口 6 → 12）

| 指标 | 扩展前 | 扩展后 |
|---|---|---|
| 渲染消息数 | 6 | 12 |
| scrollHeight | 3430 | 4408 |
| scrollTop | 2784（底部） | 978 |
| 最大 scrollTop | 2785 | 3763 |
| 锚点相对偏移 | 81.33 | 81.33 |

- 锚点偏移变化：**0px**；
- 扩展后 scrollTop（978）远小于 max（3763），**没有跳到底部**；
- 新增内容高度 978px，scrollTop 同步 +978，符合锚点补偿预期。

### 第 2 次扩展（12 → 18，2.4 秒采样）

- 渲染消息数：12 → 18；
- scrollTop：稳定在 883；
- 锚点（视口内第一条消息）相对偏移：稳定在 -181（2.4 秒内未变）；
- max scrollTop：4646，**未跳底**。

### 第 3 次扩展（18 → 24，90 帧逐帧采样）

- 渲染消息数：18 → 24；
- 帧级采样 90 帧，锚点相对偏移仅从 -181 变为 -180.7（亚像素差）；
- 唯一被标记的「跳变」帧是扩展后视口首条消息身份变化（新消息插入，属预期），不是视觉跳动；
- max scrollTop 5596，实际 scrollTop 950，**未跳底**。

## 结论

- 向上窗口扩展（加载更早消息）时，视口内容保持稳定，无跳底、无明显跳动；
- 修复采用的「锚点元素 + 相对位置 + rAF 复校」策略在真实长会话上有效；
- 与 commit 1502404 的预期行为一致。

## 覆盖与未覆盖

**已覆盖**：真实长会话的向上窗口扩展（6→12→18→24，共 3 次），程序化滚动触发；帧级采样。

**未覆盖**：

- 物理滚轮/触控板连续滚动（本次为程序化 scrollTop，触发路径相同但输入方式不同）；
- 「区间浏览」向下补齐（expandNewer）；
- 导航条跳转到窗口外旧消息的跳转路径；
- 生产安装包（本次为 dev 实例）。

建议发版前由用户再做一次真实滚轮手感确认；如无异常即可发布。
